# ResultFlow

A browser-based student exam result processor with roll normalization, Students/Web Roll matching, optional MCQ and CQ sources, manual corrections, validation, dense ranking, and PDF/XLSX/CSV export.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
npm run build
```

## Deploy

The project includes `vercel.json` and is ready for Vercel deployment as a Vite application.
